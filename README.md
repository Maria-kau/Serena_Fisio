# 🌿 Serena Fisio

**Landing Page para Fisioterapia**

Projeto front-end desenvolvido para apresentar os serviços de fisioterapia, facilitar a navegação dos visitantes e oferecer um canal de solicitação de agendamentos.

A proposta é proporcionar uma experiência digital moderna, intuitiva e acolhedora, transmitindo profissionalismo e confiança.

## 🌐 Demonstração

Acesse o projeto publicado:

**[Serena Fisio — Visualizar site](https://maria-kau.github.io/Serena_Fisio/)**

## ✨ Funcionalidades

- **Apresentação profissional:** seção inicial com informações sobre a profissional.
- **Sobre:** apresentação e descrição profissional.
- **Serviços:** exibição das especialidades e modalidades de atendimento.
- **Dúvidas:** formulário interativo para envio de perguntas.
- **Agendamento:** formulário para solicitação de consultas pelo WhatsApp.
- **Navegação:** menu interativo com acesso às seções da página.
- **Responsividade:** interface adaptada para desktops, notebooks, tablets e smartphones.

## 📱 Responsividade

O projeto foi desenvolvido com layout responsivo, adaptando sua estrutura e seus elementos para diferentes tamanhos de tela.

A experiência de navegação foi trabalhada para garantir:
- Melhor distribuição dos elementos.
- Adaptação do menu para dispositivos móveis.
- Ajuste de imagens, textos e componentes.
- Navegação mais confortável em telas menores.
